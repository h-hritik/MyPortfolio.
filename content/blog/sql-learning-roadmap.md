## Where I Am Now

I am currently working as an SQL Developer, managing and optimising data on MS SQL Server day-to-day. My core skills are T-SQL, stored procedures, complex joins, MIS reporting and data validation.

## Where I Am Going

My target over the next 12–18 months is to deepen into:

1. **Oracle SQL / PL/SQL** — to be effective across both major RDBMS platforms
2. **Advanced query optimisation** — execution plans, index design, statistics
3. **Power BI** — to close the gap between SQL output and business dashboards
4. **Database administration basics** — backup/recovery, user management, maintenance plans

## How I Am Getting There

- Reading official documentation and practising on a local SQL Server / Oracle XE instance
- Working through courses on Microsoft Learn and other platforms
- Building small case studies on this site to document what I learn
